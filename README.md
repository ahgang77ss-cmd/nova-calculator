# ماشین حساب Nova 🧮

سوپر اپ حساب فارسی — ماشین‌حساب هوشمند، تبدیل واحد، مالی، برنامه‌نویس، سلامت و نمودار تابع.

## ✨ ویژگی‌ها

- **ماشین‌حساب هوشمند:** عبارت کامل، درصد (`15% of 240`)، تخفیف (`20% off 99`)، انعام (`tip 15% on 85`)، نتیجه زنده
- **تبدیل واحد:** طول، وزن، دما، زمان، دیتا، مساحت، حجم، سرعت — آفلاین
- **مالی:** قسط وام ماهانه + درصدگیری
- **برنامه‌نویس:** تبدیل مبناهای dec / hex / bin / oct
- **سلامت:** شاخص BMI
- **نمودار:** رسم چند تابع همزمان
- **PWA:** قابل نصب روی موبایل و دسکتاپ، کار آفلاین با Service Worker

## 🚀 اجرای محلی

```bash
python -m http.server 8000
# بعد باز کن: http://localhost:8000
```

> سرویس‌ورکر روی `file://` کار نمی‌کند؛ حتماً از طریق http(s) بازش کن.

## 📲 نصب

- **اندروید:** کروم → منو → Install app
- **آیفون:** سافاری → Share → Add to Home Screen
- **دسکتاپ:** کروم/Edge → آیکون نصب کنار آدرس‌بار

## 🛠 تکنولوژی

HTML + CSS + JavaScript خالص — بدون هیچ کتابخانه‌ای. موتور محاسبه امن (Shunting-Yard، بدون `eval`).
